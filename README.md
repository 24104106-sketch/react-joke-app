# Jest a Minute

A small, responsive React app that fetches a random joke from the [Official Joke API](https://official-joke-api.appspot.com/). A new joke is loaded when the app opens; use **Tell me another** to fetch another one. If the request fails, the app displays the error and lets you retry.

## Run locally

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```
